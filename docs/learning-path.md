# Учебный маршрут

Порядок, в котором карточки справочника читаются с нуля. Сам справочник сгруппирован
по осям, а не по сложности, — читать его подряд с первой карточки не нужно.

Правило плотности, выведенное из четвёртого занятия: **не больше 3–4 карточек за раз**,
из раздела XII — **не больше двух**. Занятие, где взяли пять сложных подряд, кончилось
тем, что последнюю бросили на середине.

## Раздел XII (AI-эра) — в конце, а не в начале

Четвёртое занятие начали с раздела XII, минуя маршрут выше. Результат: p48–p50 прошли
поверхностно, p51 не зашла вообще, p57 бросили. Раздел выглядит доступным, потому что
слова знакомы, но опирается на observability, контракты и понимание тестирования, которых
в маршруте ещё не было.

| №                                               | Требует до                                                                       | Статус                   |
| ----------------------------------------------- | -------------------------------------------------------------------------------- | ------------------------ |
| [48](https://nikolay-e.github.io/learning/#p48) | p2 (пройдено), p32 (не пройдено) — prompt injection есть частный случай парсинга | поверхностно             |
| [49](https://nikolay-e.github.io/learning/#p49) | p33; least privilege для агентов — то же least privilege                         | поверхностно             |
| [50](https://nikolay-e.github.io/learning/#p50) | p20 (обратимость решений), p22 (идемпотентность) — оба не пройдены               | поверхностно             |
| [51](https://nikolay-e.github.io/learning/#p51) | p9 — «тест проверяет свойство, а не пример»; без этого карточка не читается      | провал, нужен повтор     |
| [57](https://nikolay-e.github.io/learning/#p57) | продакшн-опыт с трейсингом (p28, p29, p31)                                       | пропустить на этом этапе |

p51 повторяется после p9 и p28 — конспект с нуля лежит в
[`lessons/051-evals.md`](lessons/051-evals.md), он не требует ни того, ни другого и
годится как временная опора.

p57 не чинится конспектом: семантические конвенции OpenTelemetry человеку без
продакшн-трейсинга не нужны. Карточка справочника не обязана быть лекцией — эта помечена
как «для работающих с трейсингом» и пропускается, а не упрощается.
